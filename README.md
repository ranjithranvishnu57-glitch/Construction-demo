# BuildNext Construction Website

A world-class, premium construction company website built using pure **HTML5, CSS3, and Vanilla JavaScript** only. Designed with an editorial luxury architecture studio aesthetic.

## Features

- **Cinematic Hero Section**: Masked line-by-line typography reveal, subtle background Ken Burns zoom, and interactive cursor parallax.
- **Editorial About Section**: Overlapping architectural imagery with experience badge and company differentiators.
- **Service Presentations**: Editorial cards featuring custom typography, numbered badges, and hover lifts.
- **Featured Projects Portfolio**: Asymmetric editorial layout with a fully accessible interactive Project Detail Modal.
- **Measurable Metrics**: Dark navy statistics banner with smooth IntersectionObserver count-up animations.
- **4-Step Process Timeline**: Horizontal timeline on desktop with dynamic scroll progress bar and responsive vertical mobile layout.
- **Client Testimonials Carousel**: Accessible carousel with dot indicators, prev/next buttons, and touch-swipe support.
- **Interactive Consultation Form**: Client-side field validation with real-time feedback and demonstration confirmation status.
- **Responsive & Accessible**: Mobile-first design, fluid typography, keyboard accessibility, and `prefers-reduced-motion` compliance.

## Technology Stack

- **HTML5**: Semantic markup & SEO metadata
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, custom bezier transitions
- **Vanilla JavaScript**: ES6 modules, IntersectionObserver, modal focus trapping, touch swipe

## Getting Started

1. Clone or download this repository.
2. Open `index.html` directly in any modern browser.
